## Earlier experimental work

Rain ZHAO (`RainChinChao`) developed flexible-flow and pblock/retiming composition prototypes. Later compatibility tooling supports the cascaded-flow approach without including the original prototype scripts as the main implementation.

Ramesh Krishnamurthy developed an experimental regret-aware LLM meta-controller and selector. This entry recognises that earlier research work, not authorship of the current runtime selector.

## Upstream foundations

LATCH builds on AMD’s FPL26 contest software, including the MCP tool servers, operation wrappers, baseline optimiser and validator. The upstream history includes work by Chris Lavin and Preston Walker, including the reactive-stimulus validator. RapidWright and the MCP Python SDK retain their own contributor acknowledgements and licences. See [Source credits](SOURCE_CREDITS.md) and [Licensing](LICENSING.md).

Development and documentation included AI-assisted work under human direction and review.

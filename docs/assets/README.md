# Manuscript figures

These standalone figures are extracted from *LATCH: LLM-Assisted Timing Closure
Harness for Post-Route FPGA Optimisation*, manuscript revision shared on
9 October 2026. Each PDF contains the target figure and its own resources,
without surrounding manuscript text, other figures or page annotations.
The visible crops, plotted values and labels are unchanged. DoF and ablation
PDFs retain the original vector text and drawing; the overview retains its
original raster illustration. PNGs provide unchanged browser previews.

| Asset | Manuscript source | Interpretation |
|---|---|---|
| [Overview](latch-overview.pdf) | Figure 1, page 3 | Shared architecture and control interfaces |
| [DoF results](dof-results.pdf) | Figure 5, page 7 | Functional-pass rates; gain distribution conditional on passing |
| [Ablation results](ablation-results.pdf) | Figure 8, page 9 | Per-design S0–S3 results; best-of-three repeats, not averages |

These are reported manuscript results, not new measurements of this checkout.
The older curated data package is not established as a complete numerical
source for this revision, including its updated Pico results. Consult
[data reproduction](../latch-data-reproduction.md) before attempting a redraw.
New smoke runs must remain separate from paper data.

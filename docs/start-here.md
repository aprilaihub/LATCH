# Start here

1. [Install and run the tool/model-free example](../README.md).
2. Read [Harness CLI/API and lifecycle](latch-harness.md).
3. Choose [DoF](../experiments/dof/README.md) or [S0–S3](../experiments/ablation/README.md).
4. Set up [explicit tools and validation material](latch-tools.md) for physical work.
5. Use [data interfaces](latch-data-reproduction.md) for analysis/redrawing.
6. Read [architecture](architecture/overview.md), [module ownership](latch-organization.md)
   and [sources/permissions](../SOURCE_CREDITS.md) before extending or sharing.

Mock examples use fixtures and make no tool or model calls. Custom Python runs
without a sandbox. For physical runs, prepare external tools and licenses,
matching input/golden checkpoints and the validation material required by the
chosen study. See the tool guide for installation details and the study guides
for conditions and validation schedules.
